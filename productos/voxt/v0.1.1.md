# VOXT 0.1.1 para Windows 11 x64

Chat con Ollama local, dictado opcional con Whisper y lectura de respuestas por voz. VOXT se ofrece para uso gratuito según los términos incluidos en el ZIP.

- Descarga: `VOXT-0.1.1-win-x64.zip` (220729344 bytes).
- SHA-256: `3567273a5bf28b51fe4944aaa98c53839594c4ceddb6b0effcd2bd91f9700ec1`.
- Requisito: [Microsoft Visual C++ Redistributable v14 x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Instala y configura Ollama local para usar el chat.
- Los avisos, textos de licencia e instrucciones de sustitución de bibliotecas están en el ZIP y en `VOXT-0.1.1-avisos-y-licencias.zip`. Los doce archivos fuente de Qt y Qt for Python 6.10.2 se ofrecen como adjuntos de esta release. El catálogo de fuentes con sus hashes está en `LICENCIAS/Qt-sources.json`.

[Ayuda y soporte de VOXT](https://voxt.site.je/?p=ayuda)
